# 🌍 Tu País

**Tu País** es una aplicación web de adivinanzas geográficas donde el usuario debe identificar países a partir de sus banderas. El proyecto está enfocado en una experiencia de usuario ágil, lógica de estado clara y una arquitectura escalable, desarrollada sin frameworks.

## 🚀 Demo en vivo
👉 santiagogoncalvez.github.io/tupais/

## 🧠 Concepto
El proyecto invierte la idea tradicional de sitios como Flagpedia: prioriza el juego y la interacción, y complementa con información contextual sobre los países.

## ✨ Características
- Adivinanzas por reconocimiento visual de banderas
- Sistema de gamificación simple
- Estado global centralizado (inspirado en Flux)
- Routing por hash
- Interfaz rápida y sin dependencias externas

## 🛠 Tecnologías utilizadas
- HTML
- CSS
- JavaScript (Vanilla)

## 🏗 Arquitectura
- Gestión de estado global propia
- Separación de lógica y vista
- Estructura modular y mantenible
- Enfoque en rendimiento y simplicidad

## 🎯 Objetivo del proyecto
Explorar patrones de arquitectura frontend, manejo de estado y experiencia de usuario sin apoyarse en frameworks, priorizando el control total del flujo de la aplicación.
